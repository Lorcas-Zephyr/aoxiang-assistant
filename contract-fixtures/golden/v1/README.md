# Golden Fixture Suite v1

This directory is the cross-platform behavior corpus for the Android and iOS
implementations. It contains fictional inputs and independently authored
expected outputs only. It is not a backup format and never contains account
credentials, WebView data, or verification secrets.

## Layout

`manifest.json` is the only index. Each scenario has a stable kebab-case `id`,
a `kind`, an `input` JSON path, an `expected` JSON path, and optionally an
`html` path. Paths are relative to this directory and always use `/`.

```json
{
  "id": "grades-component-html",
  "kind": "grades-component-html",
  "input": "grades-component-html/input.json",
  "html": "grades-component-html/detail.html",
  "expected": "grades-component-html/expected.json"
}
```

JSON and HTML files are UTF-8. Object member order is insignificant. Expected
values are literal golden answers and must not be generated by the code under
test. All dates are `YYYY-MM-DD`, section times are `HH:mm`, runtime instants
are ISO-8601 values with an explicit offset, and business time calculations use
`Asia/Shanghai`. Repeat rules use `""`, `"仅单周"`, and `"仅双周"`; IDs are
opaque strings.

## Scenario coverage

| Scenario | Frozen behavior |
| --- | --- |
| `grades-api-response` | Published grade rows, course-name fallback, grade detail payload, GPA API response |
| `grades-component-html` | HTML grade-component text normalization |
| `grades-gpa-portrait-fallback` | Missing API GPA retains rows and reads GPA from portrait HTML |
| `grades-retake-same-name` | Same-name retake keeps the highest score |
| `schedule-empty` | Empty timetable preserves an explicit semester end date |
| `schedule-mixed-repeat` | Mixed odd/even markers keep a rule per week segment |
| `schedule-non-contiguous` | Discontinuous weeks are not widened into an invented range |
| `schedule-friendship-summer` / `schedule-friendship-winter` | Friendship campus seasonal section times |
| `schedule-teachers-locations` | Multiple teachers and meeting-specific locations |
| `schedule-online-filter` | Online courses are excluded from the schedule payload |
| `electricity-settlement` | Asia/Shanghai 00:00-01:00 settlement deferral |
| `electricity-anomaly` | Missing, negative, and malformed balances fail closed |
| `auth-states` | Successful login, credential error, SMS challenge, expired authentication |
| `update-diff-notifications` | Course diffs and deterministic notification text |

## Platform test rule

Android JVM tests load the manifest and referenced files from the repository
test resources. The iOS XCTest target must copy this same directory without
rewriting JSON or HTML and resolve paths relative to the manifest. Both targets
must assert the `expected` files directly; platform-specific UI or WebView
session state is outside this corpus.

Do not add `password`, `cookie`, `token`, `account`, `studentId`, `captcha`,
`smsCode`, or `verificationCode` fields. Authentication fixtures may use phase
labels such as `sms_required`, but never include a code or session value.
