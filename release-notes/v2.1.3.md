# 翱翔助手 v2.1.3

## 自动更新刷新

- 后台更新成绩、课表或电费后，已经打开的应用会立即重载数据并刷新首页及对应页面。
- 从后台返回应用或点击更新通知进入时，会补查更新版本，避免出现“通知有变化但页面仍为空或显示旧数据”。
- 页面刷新沿用原位替换方式，不会先清空当前页面。

## 变化通知

- 本地成绩或课表被清空后重新同步时，恢复的数据会按全部新增内容生成通知。
- 成绩和课表均会列出发生变化的课程；课程较多时显示总数。

## 小组件预览

- 为 GPA `1×1`、剩余电费 `1×1`、GPA 与电费 `2×1/4×1`、首页数据概览 `2×2/4×1` 补充系统选择器预览图。
- 预览包含示例数据和尺寸标注，并兼容使用 `previewImage` 的旧桌面启动器。
