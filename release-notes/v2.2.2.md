# 翱翔助手 v2.2.2

## 小组件修复

- 课表周视图新增“全部课程”模式，可查看当前学期所有周次的课程；同一时间的多门课程会拆分为独立课程块并可分别查看详情。
- 修复 `4~6(双),7~9(单)周` 等混合单双周表达式的解析，分别应用每段周次的单双周规则。
- 优化课表课程块和桌面小组件的长课程名换行，地点支持多行显示。
- 修复今天没有课程、明天有多门课程时，双日课表小组件左侧出现多余空色块的问题。
- 今天或明天无课时只显示一次对应提示，后续空白行保持透明。
- 修复小尺寸课表小组件无课状态产生额外空白行的问题。

本版本可以直接覆盖 v2.2.1 安装，已有账号和本地数据会保留。
