# 翱翔助手 v2.2.0

## 结构化数据采集

- 成绩、GPA 和课表更新优先使用教务系统同源结构化接口，手动更新、登录后同步和后台自动更新使用同一套解析流程。
- 成绩请求增加 12 秒超时并按每批 4 个学期并发读取；个别学期失败不再拖住整个同步，全部失败时会自动重试。
- 修复成绩构成显示 HTML 源码的问题；同名重修课程继续只保留最高成绩，GPA 从学生画像接口读取。
- 课表准确读取完整地点、多名教师和不连续周次，并按学期起止日期及最后一门课选择当前学期；有效空课表也会保存。

## 后台更新

- 后台采集使用私有虚拟显示维持不可见 WebView，成功后才记录本次更新时间，失败不会伪装成完成。
- 已在 vivo 真机验证：从最近任务划掉应用后，系统可以按时重新启动同步、恢复被清空的课表、关闭进行中通知并发送课程变化通知。
- vivo/iQOO 的后台权限设置新增“后台耗电”入口。请在系统页面为翱翔助手选择“允许后台耗电”，否则 OriginOS 可能冻结同步进程。

## 开发文档

- 新增 `docs/API.md`，记录教务和一卡通数据路径、请求参数、关键响应字段、采集状态协议、失败回退及敏感信息边界。
