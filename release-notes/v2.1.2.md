# 翱翔助手 v2.1.2

## 桌面小组件

- 新增 GPA、剩余电费、GPA 与电费组合、首页数据概览小组件，支持 `1×1`、`2×1`、`4×1` 和 `2×2` 尺寸。
- 首页数据概览宽版调整为 `4×1`，保留 GPA、加权成绩、课程数和剩余电费四项数据。
- 修正 `1×1` 剩余电费组件数值偏右的问题。
- 手动或后台更新成绩、电费后，小组件会立即同步刷新；退出登录后会清空对应数据。

## 友谊校区作息

- 课程地点包含“友谊”即可自动识别为友谊校区。
- `5月1日-9月30日` 使用友谊校区夏季作息，`10月1日-4月30日` 使用冬季作息。
- 首页今日课程、周课表课程块和桌面课表小组件会显示对应校区的准确时间。
- 当周全部课程都在友谊校区时，周课表左侧时间同步切换；混合校区时保留长安时间轴，各课程仍显示自身时间。
