# 翱翔助手 v2.3.0

## 全新界面

- 首页、课表、成绩、管理和设置页面采用统一的轻量玻璃风格，重新调整信息层级、图标、圆角和间距。
- 移除按钮和卡片上生硬的系统阴影，浅色与深色模式均使用更克制的边界和层次。
- 首页增加外观快捷切换；成绩、电费更新按钮采用不同图标和配色；今日课程显示时间、地点与教师。
- 管理页改为紧凑列表，移除课程和学期的新增、编辑、删除入口。

## 成绩与课表

- 成绩页突出显示总 GPA 和每门课程绩点，分数作为辅助信息展示。
- 课表页采用“本周 / 全部课程 / 月历”分段选择器，并统一学期选择、周次导航和手动更新按钮。
- 连续 2 节、3 节及更多节次保持为一个完整课程块；接口将连续课程拆成相邻记录时也会自动合并。
- 修复全角周次分隔符及复杂单双周格式解析；同一天同一课程有多段时间时，首页会显示全部课程。
- 成绩接口部分学期暂时失败时不再覆盖完整本地数据，并使用延迟重试，避免持续重复采集。

## 稳定性

- 改进统一认证跨域 Cookie 和登录凭据持久化，降低登录成功后同步再次失效的概率。
- 优化成绩与课表更新通知的差异识别。
- 修复深色课表小组件背景及部分桌面启动器的小组件初始化兼容问题。

本版本可以直接覆盖 v2.2.2 安装，已有账号和本地数据会保留。
