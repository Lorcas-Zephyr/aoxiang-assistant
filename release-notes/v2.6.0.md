# 翱翔助手 v2.6.0

## 更新内容

- 新增“事项”页面，集中查看考试、手动日程和清单，也可设为打开应用时进入的页面；手动日程和清单入口由管理页移至事项页。
- 首页数据概览显示网费余额，并提供成绩、电费、网费三个更新入口；移除独立网费卡片，将校车出行放到“今日课程和考试”下方。
- 统一日程页返回箭头的图标和大小，移除考试信息标题旁的场次数量，精简课表页的日程入口与重复展示。
- 网费手动与自动更新共用会话恢复逻辑，已验证的独立网费会话加密保存；有效会话可直接同步并返回，服务端失效后仍需在校方页面完成验证码登录。
- 更新应用图标；首页课程与考试合并展示，事项页默认显示未结束的考试，“全部”进入完整考试列表。
- 考试与日程按实际时间在课表节次内按比例显示，连续课程保持完整；改进考试标题换行。
- 完善网费后台调度、成功后返回及首页刷新，修复网页顶部被状态栏遮挡的问题。
- 支持扫描二维码导入课表，成绩明细展示可读取的教学班排名；账号被校方锁定时暂停自动更新。
- 修复更新考试覆盖其他学期、重复日程未展开、错过清单提醒未补发，以及退出账号后残留考试、排名或网费缓存的问题。

本版本可直接覆盖旧版安装，已有账号、课表、成绩和设置数据会保留。

网费使用独立校园网账号。会话保存不能延长校方服务端有效期，遇到验证码或会话过期时，请在网费页面重新登录。
