# 翎翔助手 v2.1.0

## 课表同步

- 课表同步优先读取教务系统结构化数据，并兼容不同账户的页面加载时机和模板差异。
- 自动识别全部学期及网页中的学期起始日期，按当前日期选择正确课表。
- 学期结束时间根据最后一门课计算，且至少保留两周；只有超出结束日期才会切换到下一学期。
- 手动更新课表时不再因页面文字误判而跳回教务首页。

## 登录与采集

- 放宽统一身份认证成功判定：进入 `uis.nwpu.edu.cn` 后跳出该站点即视为认证通过，同时支持任意有效的教务学生页面。
- 隐藏的密码框不再被误判为登录页，只有明确的账号或密码错误才计入登录失败。
- 设置页新增“手动更新”二级页，可分别选择电费、成绩和课表采集时是否显示网页；后台自动更新始终隐藏网页。

## 后台更新

- 新增通知、精确定时、电池优化豁免及厂商自启动/后台运行权限检查。
- 使用系统精确闹钟在下次同步时唤醒应用，应用退到后台或进程退出后仍保留更新计划。
- 权限检查结果改为原位刷新，解决“检查并授权”和返回设置页时的闪烁。

## 其他修复

- 修复检查更新时 GitCode 空发布描述显示为 `null` 的问题。
