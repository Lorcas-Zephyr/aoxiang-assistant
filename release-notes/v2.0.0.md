# 翱翔助手 v2.0.0

## 登录与启动

- 登录和切换账号继续使用 App 内账号密码弹窗；连续两次失败后自动打开校方统一认证页面。
- 只有认证后实际进入教务系统首页才判定登录成功，账号状态会立即刷新。
- 设置页可选择打开应用时进入首页、课表、成绩、管理或设置页。

## 成绩与 GPA

- 更新成绩时从学生画像读取个人 GPA，加权成绩仍在本地按课程成绩和学分计算。
- 同名课程存在重修记录时只保留分数最高的一条。
- 修复画像页结构导致 GPA 一直读取的问题；读取失败超过 15 秒会保存成绩并保留原 GPA。

## 同步与显示

- 首页、成绩、课表和管理页在数据更新后立即刷新，不再等待重新进入页面。
- 页面使用就绪后原位替换，避免数据刷新时出现空白闪烁。
- 应用内更新按钮会直接打开对应版本的 GitCode APK 下载地址。
