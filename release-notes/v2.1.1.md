# 翱翔助手 v2.1.1

## 登录与采集

- 除主动退出或切换账号外不再清除认证 Cookie，登录和采集成功后立即持久化会话，避免后续更新重复触发短信风控。
- 成绩、课表或电费采集遇到登录失效、短信验证码或安全验证时，会切换到可见的统一认证页面。
- 人工认证通过后保留同一会话，自动继续原采集任务，并遵循该采集项原有的网页显示设置。
- 补充当前地址、页面完成及历史跳转的多重认证状态检测，兼容部分手机 WebView 遗漏重定向回调的情况。

## 后台权限

- 移除无效的“检查并授权”按钮，各项权限改为使用独立设置入口。
- 从系统设置返回后立即原位刷新可检测的权限状态。
- 厂商自启动权限因 Android 不提供统一检测接口，状态明确显示为“无法检测，请自行确认”。
